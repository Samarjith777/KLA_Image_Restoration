## Model
V4 Noise-Aware Detail Restoration

## Standalone evaluation

From the project root:

```powershell
.\.venv\Scripts\python.exe .\evaluate.py <input_directory> <output_directory>
```

Example:

```powershell
.\.venv\Scripts\python.exe .\evaluate.py .\test_images .\outputs
```

The evaluator:
- accepts an input directory containing `.npy` degraded images
- loads the V4 checkpoint
- restores each 128Ã—128 image to 256Ã—256
- clamps outputs to [0, 1]
- writes `.npy` float32 outputs using the original filenames

## Model configuration

```text
V4NoiseAwareRestoration
in_channels = 1
out_channels = 1
channels = 64
num_blocks = 6
```

## Local validation

The V4 experiment was evaluated on 320 paired validation samples.

V4 validation metrics:

```text
PSNR  : 28.3314 dB
SSIM  : 0.765930
LPIPS : 0.258063
```

These are project validation results, not official H100 challenge scores.

## Submission outputs

The `outputs` directory contains the restored outputs generated by the standalone evaluator from the project's `NoisyLR` input directory.

The verified run processed 3,200 input `.npy` files and produced 3,200 output `.npy` files.

## Environment

`requirements.txt` contains the environment captured with `pip freeze`.

## Training

`train_v4.py` is the V4 training/reproduction script. It uses the project's dataset, train/validation splits, V4 model implementation and saves V4 checkpoints.

## Important benchmark note

Local inference was performed on an NVIDIA GeForce RTX 3050 Laptop GPU. This must not be presented as the official KLA H100 benchmark.
