# KLA AI Hackathon - AI-Based Image Restoration



## Project Overview



This project addresses AI-based restoration of degraded semiconductor inspection images.



The objective is to reconstruct 256x256 images from degraded 128x128 input images while preserving structural and fine-detail information.



The final submission uses the V4 Noise-Aware Detail Restoration model.



## Final Model



### V4 Noise-Aware Detail Restoration



The V4 model combines:



- Pixel-level reconstruction

- Edge-aware restoration

- Fine-detail preservation

- Noise-aware processing



### Model Configuration



Model: V4NoiseAwareRestoration

Input channels: 1

Output channels: 1

Channels: 64

Blocks: 6

Input size: 128x128

Output size: 256x256

## Standalone Evaluation



The evaluation script accepts:



1\. Input directory containing degraded .npy images

2\. Output directory for restored .npy images



Run:



.\\.venv\\Scripts\\python.exe .\\evaluate.py <input_directory> <output_directory>



Example:



.\\.venv\\Scripts\\python.exe .\\evaluate.py .\\test_images .\\outputs_test



The evaluator:



- Loads the V4 trained checkpoint

- Processes all .npy input images

- Restores 128x128 images to 256x256

- Clamps output values to \[0, 1]

- Saves float32 .npy outputs

- Preserves original filenames

- Verifies input/output counts



No manual modification of evaluate.py is required.



## Input Format
